# Group

A group is a set $G$ with an operation $\circ$ that satisfies four rules:

- **Closure:** $a \circ b$ belongs to $G$.
- **Associativity:** $(a \circ b) \circ c = a \circ (b \circ c)$.
- **Identity:** an element $e$ satisfies $e \circ a = a \circ e = a$.
- **Inverses:** each $a$ has an inverse $a^{-1}$ with $a \circ a^{-1} = a^{-1} \circ a = e$.

Integers under addition form a group. The identity is 0; the inverse of $a$ is $-a$.

[Source: MIT, Introduction to Groups](https://symm4ml.mit.edu/symm4ml_s26/notes/intro-to-groups).
