# Cyclic group

A cyclic [[group]] is generated by one element $g$: every element is $g^k$ for some integer $k$.

For example, addition modulo 6 forms a cyclic group. Repeatedly adding 1 reaches every element:

$$0, 1, 2, 3, 4, 5.$$

The element 2 generates the [[subgroup]] $\{0,2,4\}$ instead.

[Source: MIT Algebra I notes, §2.4](https://ocw.mit.edu/courses/res-18-011-algebra-i-student-notes-fall-2021/mit18_701f21_full_lec_new.pdf).
