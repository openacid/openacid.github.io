# Lagrange's theorem

For a finite [[group]] $G$ and a [[subgroup]] $H$, the size of $H$ divides the size of $G$:

$$|G| = [G:H]\,|H|.$$

The index $[G:H]$ counts the distinct left [[coset|cosets]]. Each coset has $|H|$ elements, and together they partition $G$.

For addition modulo 6 and $H=\{0,2,4\}$, the count is $6=2\times3$.
